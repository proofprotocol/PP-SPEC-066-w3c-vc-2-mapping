# Contributing

PP-SPEC-066 is maintained as part of the Proof Protocol specification series.

Contributions may be submitted as issues or pull requests.

Contributions should preserve Proof Protocol's framework-agnostic architecture, distinguish W3C Verifiable Credentials Data Model v2.0 concepts from Proof Protocol concepts, identify sources clearly, respect upstream licensing and trademarks, and preserve the normative meaning of the specification.

By contributing, you represent that you have the right to submit the contribution.
