## Purpose

This repository defines a Proof Protocol mapping between Verifiable Credentials Data Model v2.0, W3C Recommendation, 15 May 2025 and Proof Protocol evidence, efficacy, and proof semantics.

W3C Verifiable Credentials Data Model v2.0 is treated as an interoperability standard that can express, carry, or register Proof Protocol artifacts. Proof Protocol remains framework-agnostic and independently establishes whether a selected control performed as claimed.

## Architectural principle

> **Threat, control, audit, regulatory, and interoperability frameworks are pluggable inputs to Proof Protocol. Proof Protocol is framework-agnostic.**

External frameworks and standards identify what may be tested or how results may be carried. Proof Protocol independently establishes whether a control worked and what evidence proves the result.
